# MuleNet Data Pipeline & Artifacts

## 1. Directory Structure
- `/data/raw`: Place raw IBM AML CSVs (`HI-Small_Trans.csv`, `Accounts.csv`) here.
- `/data/processed`: Cleaned parquet files generated by feature engineering:
  - `accounts.parquet`: Cleaned account master table with entity joins.
  - `events.parquet`: Synthetic account lifecycle event log (password/email edits, device additions, logins).
  - `transactions.parquet`: Historical transaction records with canonical IDs (`sender_id = from_bank + "_" + account`).
  - `ground_truth.parquet`: Labeled synthetic positive sequences and injected mule rings.

## 2. Injected Patterns & Ground Truth
1. **Positive Sequence Patterns (~5% of accounts):**
   - `credential/contact_change` $\to$ `payee_added` $\to$ `large_transfer` in $< 10$ minutes.
2. **Synthetic Mule Rings (15–20 injected rings):**
   - 3-to-5 node circular money flows ($A \to B \to C \to A$) and shared device syndicates (`SHARES_DEVICE`).
